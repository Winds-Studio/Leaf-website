description: "How to do a backup for your server"
---

It's always important to do a backup before doing risky operations, especially upgrading to a new Minecraft version, switching between server software forks, or doing a data migration. Even if data corruption happens, you can restore your data from the backup without losing it permanently.

Except for a full backup, taking backups regularly is also the recommended practice.

<Callout title="Tip" type="tip">
  If you run servers on a game hosting provider, they probably already provide backup feature, asking their support first before planning to conduct backup manually by yourself.
</Callout>

## Full backup

It's strongly recommended to taking a full backup before conducting a risky operation.

Backup important files, including but not limit to:
- Databases dump
- World folders
- Plugin configurations / data / Jar files
- Server configuration files

Archive them, and store them in safe places, e.g., backup disk, cloud drive, or cloud storage services.
