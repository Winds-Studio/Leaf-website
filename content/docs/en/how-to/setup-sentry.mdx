[Sentry](https://sentry.io/) is an error monitoring platform that captures exceptions with full stack traces and context in real time. By integrating it with Leaf, it largely simplifies the manual effort of tracking errors, making it easier to track issues and implement fixes.

This guide provides a detailed walkthrough of configuring Sentry and connecting it to Leaf.

## Create a Sentry account

Sentry offers a free plan with limited features for individual developers, but it is sufficient for most server needs.

If you are unsure whether your server team has a Sentry Team, contact your team first. If you already have a Sentry account, you can jump to [Create a new project](#create-a-new-project).

### Navigate to Sentry signup [step]

Go to [https://sentry.io/signup/](https://sentry.io/signup/).

You can register with your email address, or register using a supported third-party account. However, you still need to input the information shown in the next step.

<img
  src="/docs/sentry/account-creation-1.png"
  alt="Third-party signup options"
  className="mx-auto max-w-[70%]"
/>

### Input your information [step]

Input your information:
- Name - Your name.
- Organization - Your organization name. It can be the name of your server or studio.
- Email - Your email.
- Password - A strong password.
- Data Storage Location - The region you want to store your Sentry data in. Read [Data Storage Location (US or EU)](https://docs.sentry.io/organization/data-storage-location/) for more detail.

<img
  src="/docs/sentry/account-creation-2.png"
  alt="Account creation form"
  className="mx-auto max-w-[70%]"
/>

Once you have created the account, you should be on your organization dashboard page.

## Create a new project

The *project* represents Minecraft server instances of the same type. As a best practice, for example, all your lobby instances can share a project and all survival instances can share another.

Don't mix different server types in one project. Choose the granularity wisely to make maintenance more efficient.

### Go to Projects [step]

In your organization dashboard, click your organization icon at the top-left navigation bar, select **Projects**.

Then click **Create Project** at the top navigation bar.

<img
  src="/docs/sentry/project-creation-1.png"
  alt="Projects on Organization menu"
  className="mx-auto max-w-[50%]"
/>

### Set up a project [step]

Choose **Set up manually** at the bottom of the page.

<img
  src="/docs/sentry/project-creation-2.png"
  alt="Set up project options"
  className="mx-auto max-w-[70%]"
/>

### Choose platform [step]

In the *Platform* section, find and select **Java**.

<img
  src="/docs/sentry/project-creation-3.png"
  alt="Choose Java as platform"
  className="mx-auto max-w-[70%]"
/>

In the next popup box, select **Nope, Vanilla**, and click **Configure SDK**.

<img
  src="/docs/sentry/project-creation-4.png"
  alt="Select Nope, Vanilla option"
  className="mx-auto max-w-[40%]"
/>

### Select tracking features [step]

In the *Products* section, keep the default selection, which only selects **Error monitoring**.

<img
  src="/docs/sentry/project-creation-5.png"
  alt="Select Error monitoring only"
  className="mx-auto max-w-[70%]"
/>

### Input project name [step]

Input the project name.

You can use the format like `[server name]-[backend server name]`, e.g., `ciallomc-lobby`.

<img
  src="/docs/sentry/project-creation-6.png"
  alt="Project name and team fields"
  className="mx-auto max-w-[70%]"
/>

### Complete [step]

Click **Create Project**.

Then copy and save the DSN in the *Configure SDK* section. It will be used in the further steps.

<img
  src="/docs/sentry/project-creation-7.png"
  alt="Copy DSN"
  className="mx-auto max-w-[100%]"
/>

## Connect Leaf to Sentry

### Get the DSN [step]

You should already have the DSN from the previous project creation step.

However, in case you forget it, you can still find your DSN string in the settings of your project later.

(Your organization icon > **Projects** > Your project > **Project Settings** > **SDK Setup** > **Client Keys (DSN)**)

The entire URL string provided is your DSN.

<img
  src="/docs/sentry/connect-to-leaf-1.png"
  alt="Path to Project settings guide"
  className="mx-auto max-w-[70%]"
/>
<img
  src="/docs/sentry/connect-to-leaf-2.png"
  alt="Path to DSN guide"
  className="mx-auto max-w-[80%]"
/>

### Paste the DSN into Leaf config [step]

Go to the Minecraft server instance that corresponds to your created Sentry project.

In the Leaf config file, paste the copied DSN into the `sentry.dsn` setting.

### Apply config changes [step]

Save the config file, then run `/leaf reload` or restart your Minecraft server to apply the change.

Check [Leaf Global Config](../config/leaf-global) for more information about the Sentry setting in Leaf config.

You are all set!
