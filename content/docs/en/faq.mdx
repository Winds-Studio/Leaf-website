## ❓ · Which versions does Leaf support?

Leaf currently supports:
- 1.21.11
- 26.2
- 26.3

These versions will receive bug fixes and support. However, we still recommend using the latest Minecraft version supported by Leaf to get the newest optimizations, bug fixes, and active updates.

## ❓ · How much more performant is Leaf than `"<insert any paper fork>"`?

Based on feedback from actual server owners, Leaf usually brings performance improvements compared to other non-Folia Paper forks.

The exact improvement depends on server hardware specifications, server types, and actual gameplay scenarios.

We plan to provide a more comprehensive and fair performance comparison in the future.

## ❓ · Does Leaf support Spigot/Paper plugins?

Yes. Leaf aims to keep the same plugin compatibility as Paper.

However, not all plugins follow standard API usage. Many plugins depend directly on Minecraft's internal implementation, which is NMS, or use the API in non-standard ways. Such plugins may have compatibility issues after a Minecraft version update or a server core change.

Leaf will try to maintain compatibility for these plugins, but cannot guarantee that every plugin will work.

If a plugin does not work properly, you can replace Leaf with Paper and test it. If the problem only occurs on Leaf, please report it on the Leaf [GitHub Issues](https://github.com/Winds-Studio/Leaf/issues/new/choose).

## ❓ · How often does Leaf update upstream?

Usually every 1~3 weeks, depending on how important the upstream update is.

## ❓ · How can I optimize my server?

Leaf's default configuration aims to stay as close to vanilla behavior as possible. You can refer to the [Leaf optimization guide]() to further improve server performance.

## ❓ · Any known incompatibilities?

Leaf's latest version has no known compatibility issues.

However, here are some incompatibilities in legacy versions:

- < 1.21.1 of Leaf, incompatibile with [RealisticVillagers](https://www.spigotmc.org/resources/realisticvillagers.105055) plugin.
- < 1.21.8 of Leaf, if you enabled async tracker and have [Citizens](https://www.spigotmc.org/resources/citizens.13811) or any plugins using real entity as NPC, please enables tracker's `compat-mode` or disable the async tracker!

Found an incompatible plugin? [Report it here](https://github.com/Winds-Studio/Leaf/issues/new/choose)!

## ❓ · How can I support the project?

Leaf is a free and open-source project, and all contributions are made out of passion and interest. If you appreciate our work, you are welcome to support Leaf via [Open Collective](https://opencollective.com/Winds-Studio) or [Dreeam's AFDIAN (爱发电)](https://afdian.com/a/Dreeam). This is the greatest encouragement for us.

Donations are used for Leaf's infrastructure maintenance, such as CI, domain names, and other cloud services. The remainder is given back as subsidies to Leaf team members, or to other projects and organizations in the Minecraft community.
